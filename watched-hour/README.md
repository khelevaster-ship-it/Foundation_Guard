# The watched-hour pack

What a watcher needs to run beta gate line 5: three people who have never written code each set up the lock on a
small game in an hour, with nobody helping.

- `game/`: Gold Mine, a tiny game with 12 tests. It runs on the Python inside the Windows download.
- `CARDS.md`: the four cards the tester is given, and one last message.
- `WATCHER.md`: the watcher's sheet: who can test, what to prepare, the hour minute by minute, the pass lines and the
  score sheet.
- `watcher/plant.py`: the watcher's planted change for card 3.
